# Only Raiders

**Only Raiders** 是一款面向玩家的非官方独立桌面辅助参考工具，本仓库为官方**二进制发布与在线更新分发仓库**（Releases 托管）。

## 下载与更新

- **获取最新版本**：前往本仓库右侧 **[Releases](https://github.com/lulu1hao/only-raiders/releases)** 页面下载最新便携版 `only-raiders.exe`（或历史版本）。
- **内置在线更新**：应用内置版本检查、增量热更新与按需扩展包下载，支持国内镜像加速与 GitHub 直连回退。
- **数字签名保护**：所有更新清单（`update-manifest.json`、`assets-manifest.json`）与热更新包内文件清单均经过 **Ed25519 数字签名** 与 **SHA-256 完整性校验**，有效防止第三方镜像劫持或传输篡改。详见 [SECURITY.md](./SECURITY.md)。
